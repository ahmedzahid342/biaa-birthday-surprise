BIAA BIRTHDAY SURPRISE — UPDATED VERSION

WHAT'S INSIDE
- index.html, style.css, script.js
- Five-photo memory page: one photo shown at a time, animated photo frame, five captions, next/previous arrows and dots.
- Birthday wish, confetti and a real-song audio player slot.
- photos folder with instructions.

ADD YOUR 5 PHOTOS
1. Choose five photos you want to use.
2. Copy them into the photos folder.
3. Rename them exactly:
   photo1.jpg
   photo2.jpg
   photo3.jpg
   photo4.jpg
   photo5.jpg
4. Keep the same file extensions as .jpg. If a picture is PNG, convert it to JPG or update its matching filename in script.js.
The website shows one photo per slide. Each slide has its own birthday paragraph. You can edit the captions in the `memories` list in script.js.

ADD A REAL LOVE SONG
1. Choose a song you have the right to use, or a legally obtained audio file.
2. Put the audio file in the same folder as index.html and name it exactly `the official YouTube player`.
3. On the final birthday screen, press “Play music”.
This ZIP does not include a copyrighted song. A song file won't automatically upload to GitHub unless you add it yourself. If you prefer an official YouTube/Spotify embed, we can set that up instead; playback depends on that platform and its rules.

OPEN LOCALLY
- Extract the ZIP.
- Open the extracted folder in VS Code.
- Double-click index.html to test in a browser, or use Live Server.
- If you have not added your own photos/music yet, photo placeholders will appear and music will ask you to add the official YouTube player.

PUBLISH WITH GITHUB PAGES
- Upload the site files and photos folder (and the official YouTube player if you have rights to use it) into the root of a GitHub repository.
- In Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
- Wait for GitHub to show your published URL.
- Test the live site on a phone before sending it to Biaa.

PRIVACY
The site does not collect or send her answers anywhere. Keep photos and any music file you use appropriate to share.
